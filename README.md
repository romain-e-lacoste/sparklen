## Overview

The purpose of the `Sparklen` package is to provide the `Python` community with
a complete suite of cutting-edge tools specifically tailored for
the study of exponential Hawkes processes, with a particular focus
on the high-dimensional setting. It notably features:

  * An efficient cluster-based simulation method for generating events.

  * A highly versatile and flexible framework for performing inference of
    multivariate Hawkes processes.

  * Novel approaches to address the challenge of multiclass
    classification within the supervised learning framework.

## Installation

You can install `Sparklen` using **pip**, or from **source**.

### Install via pip

The easiest way to install `Sparklen` is using `pip`:

```bash
pip install sparklen
```

### Install from Source

`Sparklen` runs its computationally intensive parts in a `C++` core, connected
to `Python` through wrapper code generated by `SWIG`. Building from source
therefore needs a C++ compiler (GCC or Clang on Linux and macOS, Visual Studio
Build Tools on Windows). SWIG and NumPy are fetched automatically during the
build, so nothing else has to be installed by hand.

```bash
git clone https://github.com/romain-e-lacoste/sparklen.git
cd sparklen
pip install .
```

It's recommended to do this in a dedicated Python environment (e.g., `venv` or `conda`).
